# Contributing to this project

Thank you for considering contributing! Here’s how you can help:

1. **Reporting bugs** – Open an issue with a clear description.
2. **Suggesting features** – Use issues to propose ideas.
3. **Submitting code** – Fork the repo, create a branch, make your changes, and open a pull request.
4. **Code style** – Follow existing style and naming conventions.
5. **Be respectful** – Follow our Code of Conduct.

We appreciate your contributions!
